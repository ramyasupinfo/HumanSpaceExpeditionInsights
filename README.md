# HumanSpaceExpeditionInsights
**1. Project Title :**
                   HumanSpaceExpeditionInsights - This Project gives insights about human expedition journey to the space across various countries and companies across the world.

****2. Description :**
     - This dashboard provides key insights regarding important metrics such as Total Rockets and Total Missions of various countries across the globe. 
     - It also provides some key details regarding the missions starting from 1957 to the recent 2022.
     - The dashboard highlights on the top 6 countries which launches more missions and rockets across the world.
     - The dashboard is visually interactive among one another and contains a pop down year slicer  and a country slicer which provides the granular information to the audience about different countries and their missions across different time periods.
     - The dashboard also has the year range slicer which is used to highlight the data in the table which gives information about active and retired rockets.

**3. Tech Stack :**     

        The dashboard was built using the following tools
     📊 Power BI Desktop - Data visualization for the dashboard and report creation.
     📋 Power Query -  Used for the data tranforming and cleaning 
     💡 DAX (Data Analysis Expressions) - Used for Calculating measures, Conditional Logic and dynamic visuals.
     🧬 Dat Modeling - Relationships established among different tables and creation of star schema by creating dimension tables such as "Mission" , "Rockets" , "Countries" and "Companies"
                        tables  for cross filtering and for aggregration.
     📁 File Format - .pbix for development and .png  and .pdf for dashboard previews.

**4. Data Source :** 

      Source : The dataset for the Space Mission have been taken from the "Maven Analytics" platform which was under "cc Public Domain".

**5. Higlights/Insights :**

     1) This dataset which analyzes data till 2022 of the human journey to space speaks about some interesting insights 
     2) Space Explorations  have started from 1957 with Mission Sputnik  1 and 2  from then USSR  to about 247 missions and 65 Rocket launches from 2020.
     3) USA has contributed about 31.67 % of the total Missions followed by Russia with 30.62 %.
     4) USA has about  44.86 % of the total rocket launches while Kazakhstan stands 2nd with about 13.24%.
     5) Their have been about 4556 missions and 370 rockets launched so far. 
     6) The success rate of mission is about 91 %. while the failure rate is quiet low which makes it very interesting.
     7)  Thier are a total of 62 companies across different countries in the world. The top 5 companies are as below,
       a) RVSN USSR - Russia
       b) CASC - China
       c) General Dynamics - USA
       d) Being - USA 
       e) ULA - USA 
       The above companies contribute about 40% of the total rockets and all the other companies contribute about 60% in total.
